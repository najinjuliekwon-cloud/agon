# AGON (ἀγών)

철학사를 연대기 교과서가 아니라 **라이벌 서사**로 배우는 학습 앱.

> *agon* (ἀγών): 고대 그리스어로 겨룸, 다툼, 경기.
> protagonist(주인공)와 agony(고뇌)의 어원. 철학은 아곤에서 태어났다.

"이데아론이란 무엇인가"는 튕겨나가지만, "스승을 정면으로 반박한 제자" 이야기는 그냥 들어온다.
이 앱은 모든 개념을 **누군가가 누군가에게 화가 나서 나온 것**으로 제시한다.

철학자 52인 · 5개 시대 · 전 카드 한국어/영어 병기.

## 무엇이 들어 있나

**철학자 카드 (6단계 루프)**

| 단계 | 내용 |
|---|---|
| 씬 | 그가 열받은 구체적인 하루. 연도 + 장소 + 한 장면 |
| 한 방 | 원문 명언 → 탭하면 영어·한국어 + 왜 도발이었는지 + 출처 |
| 무기 | 명언 뒤의 개념 딱 하나 |
| 지금 여기 | 오늘의 일상으로 번역한 비유 |
| 아곤 | 같은 질문에 다른 답을 한 라이벌과의 충돌 |
| 네 차례 | 딜레마에 답하면 AI가 성향을 판정 |

**아레나** — "이 한 방, 누구?" 명언 3지선다. 오답 후보는 같은 시대에서 추출. 연승 스트릭 기록.

**오늘의 재판** — 거짓말 / 소수 희생 / 일의 의미. 철학자 3인이 변론하고 사용자가 판결.

**스탠딩** — 판정이 쌓이면 4축 레이더에 좌표가 그려지고, 52인과의 근접도가 계산된다.

## 설계 원칙

**색은 오직 대립에만.** 화면 전체가 종이(`#F4F1EA`)와 잉크(`#1A1A18`)의 무채색이다.
시안(`#0B7285`, 이성 진영)과 버밀리언(`#C1440E`, 의지 진영)은 두 철학자가 충돌하는
아곤 섹션에서만 등장한다. 그래서 **색이 나타나면 = 지금 누가 누구를 반박하고 있다는 신호**가 된다.

**시간은 색이 아니라 서체로 흐른다.** 고대는 비석에 새긴 듯 넓은 자간, 중세는 조밀한 세리프,
근대는 인쇄술의 정연함, 19세기는 무거운 디스플레이, 현대는 여백 과다의 산세리프.
스크롤하며 시대를 넘어갈 때 글자 생김새가 변하는 것이 곧 연대기다.

**초상화·사진 없음.** 죽은 백인 남자 52명의 얼굴이 나열되는 순간 이 앱은 교과서가 된다.
대신 **개념 = 하나의 움직이는 그림** 원칙으로 46종의 SVG를 직접 그렸다.
쇼펜하우어의 시계추는 실제로 고통과 권태 사이를 흔들리고, 흄의 당구공은 부딪히는데
인과의 점선이 그려지다 사라지며, 푸코의 파놉티콘은 중앙의 시선이 회전한다.
움직임 자체가 설명이므로 캡션 없이 이해된다. `prefers-reduced-motion`을 존중한다.

**AI는 생성이 아니라 해설만 한다.** 이것이 이 앱의 P0 제약이다.
명언·주장·아곤 반박은 **전부 하드코딩 큐레이션**이며, AI는 사용자 답변 판정과
재판 코멘트에만 관여한다. 그럴듯하지만 실제로는 그 철학자가 하지 않은 말이
런타임에 생성되는 순간 철학 앱은 회복 불가능하게 무너지기 때문이다.

**오귀속은 숨기지 않고 콘텐츠로 쓴다.** `myth` 필드로 8건을 표시했다.
"내가 아는 것은 내가 모른다는 것뿐"이 소크라테스의 직접 발언이 아니라는 것,
볼테르의 그 유명한 관용 선언이 사실 1906년 전기 작가 이블린 홀의 요약문이라는 것,
"신은 죽었다"가 승리 선언이 아니라 광인의 부고라는 것.

## 판정 기능에 관하여 (중요)

앱의 AI 판정은 Anthropic API를 호출한다. 환경에 따라 설정이 다르다.

| 환경 | 설정 | 판정 기능 |
|---|---|---|
| Claude 아티팩트 | 없음 (기본값) | 작동 |
| 로컬 / GitHub Pages | `VITE_AGON_API_URL` 필요 | 프록시 배포 후 작동 |

**브라우저 코드에 API 키를 직접 넣지 말 것.** 공개 저장소든 아니든,
빌드된 JS는 누구나 열어볼 수 있다. `worker/` 폴더에 Cloudflare Worker 프록시를 넣어두었다.

```bash
cd worker
npx wrangler deploy
npx wrangler secret put ANTHROPIC_API_KEY   # 여기서 키 입력
```

배포되면 나오는 주소(`https://agon-proxy.xxx.workers.dev`)를 `.env`에 넣는다.

```bash
cp .env.example .env
# VITE_AGON_API_URL=https://agon-proxy.xxx.workers.dev
```

`wrangler.toml`의 `ALLOWED_ORIGIN`을 본인 도메인으로 바꾸면 다른 사이트에서
이 프록시를 무단으로 쓰는 것을 막을 수 있다. Worker는 모델과 토큰 상한도 서버에서 고정한다.

판정 기능 없이도 카드·아레나·재판 변론은 전부 정상 작동한다.

## GitHub Pages 배포

1. GitHub에서 저장소를 만들고 이 폴더를 푸시한다
2. **Settings → Pages → Source** 를 `GitHub Actions` 로 설정
3. (선택) **Settings → Secrets and variables → Actions → Variables** 에
   `AGON_API_URL` 이름으로 Worker 주소를 등록
4. `main` 브랜치에 푸시하면 자동 배포

저장소 이름이 `agon`이 아니라면 `vite.config.js`의 `base`를 수정한다.

```js
base: process.env.GITHUB_PAGES === "true" ? "/저장소이름/" : "/",
```

## 철학자 추가하기

`App.jsx`의 `P` 객체에 항목을 추가하고, `ORDER`의 해당 시대 배열에 id를 넣는다.
`visual`은 `Visuals` 객체의 키여야 한다.

```js
newguy: {
  id: "newguy", nameKo: "…", nameEn: "…", years: "…",
  era: 4,                                  // 1~5
  school: { ko: "…", en: "…" },
  side: "reason",                          // reason | will → 충돌색
  visual: "pendulum",                      // Visuals의 키
  caption: { ko: "…", en: "…" },
  scene: { ko: "…", en: "…" },             // 구체적인 하루로
  quote: {
    original: "…", originalLang: "de",     // de|grc|la|fr|en|da|zh|pi
    en: "…", ko: "…",
    source: { ko: "…", en: "…" },          // 불확실하면 "귀속 불확실"
    sting: { ko: "…", en: "…" },           // 왜 도발이었나
  },
  weapon:  { ko: "…", en: "…" },
  analogy: { ko: "…", en: "…" },
  agon: [{ id: "rivalId", clash: { ko: "…", en: "…" } }],
  lineage: { from: [], to: [], note: { ko: "…", en: "…" } },
  myth: null,                              // 오귀속 있으면 { ko, en }
  dilemma: { ko: "…", en: "…" },
  axes: { reasonVsWill: 0, selfVsCommunity: 0, absoluteVsRelative: 0, meaningVsAbsurd: 0 },
}
```

로스터에 없는 라이벌은 `agon` 항목에 `name`, `nameEnOv`를 쓰면 카드 없이 이름만 표시된다.

**명언 규칙**: 확실한 것만. 애매하면 그 철학자의 다른 확실한 명언으로 교체한다.
그리스어는 원 스크립트 + 로마자 전사 병기. 출처(저작명 + 연도)는 필수다.

## 정확성에 관한 참고

고대 철학자의 생몰년은 학계 추정치이며 `c.` 로 표기했다.
노자는 실존 여부 자체가 논쟁 대상이라 "전설상 6C BCE"로 처리했다.
일화 중 상당수는 후대 전승(특히 디오게네스 라에르티오스)에 의존하며,
학술적 확정 사실이 아니라 널리 전해지는 이야기로 읽는 것이 정확하다.
중요한 사실을 인용할 때는 1차 자료를 확인하기 바란다.
